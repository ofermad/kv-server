# kv-server

Учебный in-memory key-value сервер на C++20 в духе Redis. Цель проекта: отработать STL, проектирование интерфейсов, тестирование, а затем многопоточность и сеть.

**Статус:** в разработке, версия 0.1 (хранилище и парсер команд).

## Что уже есть

- `Storage`: хранилище строк по ключу поверх `std::unordered_map`, операции `Set`, `Get`, `Del`.
- `ParseCommand`: разбор текстовой команды в структуру или в сообщение об ошибке.
- Unit-тесты на GoogleTest, сборка и тесты в CI на GitHub Actions.

## Поддерживаемые команды

| Команда | Что делает |
| --- | --- |
| `SET key value` | записать значение |
| `GET key` | получить значение |
| `DEL key` | удалить ключ |

Имена команд не зависят от регистра, лишние пробелы игнорируются. Значение пока один токен (без пробелов).

## Сборка и тесты

```
cmake -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Нужны CMake 3.20+ и компилятор с поддержкой C++20. GoogleTest скачивается автоматически.

## Структура

```
src/    Storage, парсер команд, main
tests/  тесты на GoogleTest
```
